# C 파트 연동 합의 안건 (A·B·E 공유용)

상태: **논의 전 초안**. 아래의 제안은 구현을 시작하기 위한 출발점이지 팀 합의가 아니다.
결정 후 담당자·결정일을 기록하고, 공통 형식이 바뀌면 Issue와 PR을 통해
`docs/interfaces.md` 및 관련 계약·샘플·테스트를 함께 수정한다.

## 공통 전제

- A의 가격·피처 → B의 PPO 학습·비중 결정 → C의 테스트 성과·통계·SHAP 평가
  → E의 FastAPI → Streamlit 흐름으로 연결한다. A의 동일가중·MVO와 KOSPI도
  C가 같은 테스트 날짜·비용·지표로 비교한다.
- 학습 구간의 정규화 통계를 테스트 구간에 재계산하지 않는다. 결정에는
  `as_of`까지 공개된 정보만 사용한다. 수익률은 비율(예: 0.01 = 1%)로 기록한다.
- 학습 보상은 성과 지표가 아니다. C의 평가는 테스트 구간의 일별 **비용 차감 후
  단순 수익률**을 기준으로 한다.
- 합의 전 변경된 파일의 소유자에게 리뷰를 요청하고, 회의에서 확정한 내용은
  회의록에도 남긴다.
